# Board Game Hub

## Project Overview

Board Game Hub is a web application that allows users to explore board games, search for games, browse different categories and view detailed information about individual games.

## Technologies Used

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Java Spring Boot
- Database: To be finalized by the team

## Main Features

- Browse available board games
- Search for board games
- Filter games by category
- View individual game details
- User registration and login
